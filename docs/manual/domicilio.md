# Domicilio

Cómo tomar pedidos para entregar o para recoger, cobrar el envío y saber quién lo llevó. Cada
sección se entiende sola.

## Cómo tomar un pedido a domicilio

**Quién:** cajero · **Dónde:** Caja → «Domicilio» → «Nueva orden», o «Pedidos» → «Nuevo a domicilio» · **Plan:** todos · **Giros:** comida
**Lo piden así:** pedido a domicilio, entrega, llevar a casa, delivery propio, pedido por teléfono

1. Entra a la venta:
   - Restaurantes: toca **«Domicilio»** y luego **«Nueva orden»**.
   - Comida rápida: toca **«Pedidos»** y luego **«Nuevo a domicilio»**.
2. Se abre **«Cliente para domicilio»**. Busca al cliente por teléfono o nombre y tócalo. Si es
   nuevo, toca **«Nuevo»** y llena **«Nombre»**, **«Calle»** y **«Colonia»**, que son obligatorios.
   Si quieres, agrega también **«Teléfono»**, **«Número»**, **«Referencias»** (por ejemplo “portón
   negro”) y la etiqueta «Casa», «Oficina» u «Otra».
3. Elige la **«Zona»**. Si la colonia ya tiene su zona, la caja la pone sola.
4. Toca **«Registrar y usar»** (o **«Guardar y usar»** si corregiste una dirección).
5. Agrega los productos. El costo de envío se suma solo según la zona.
6. Toca **«Enviar a cocina»**.

**Qué pasa después:** el pedido queda en la lista de **«Domicilio»** (en comida rápida, en
**«Pedidos»** → **«Domicilio»**). Lo cobras cuando regresa el repartidor
([Cómo asignar el repartidor](#cómo-asignar-el-repartidor)).
**Si algo falla:**
- «Calle y colonia son obligatorias para domicilio.» → llénalas.
- «Elige la zona de reparto.» → elige una zona. Si todavía no tienes zonas, toca **«Crear la
  primera zona»** o créalas en el panel
  ([Cómo configurar colonias y zonas de envío](#cómo-configurar-colonias-y-zonas-de-envío)).
- Para cambiar el costo de envío solo de este pedido, toca el renglón del envío en el ticket.
**Relacionado:** [Cómo editar los datos de una entrega](#cómo-editar-los-datos-de-una-entrega)

## Cómo tomar un pedido para recoger

**Quién:** cajero · **Dónde:** Caja → «Pick-up» → «Nueva orden», o «Pedidos» → «Nuevo para recoger» · **Plan:** todos · **Giros:** comida
**Lo piden así:** para recoger, pick-up, pasa por él, pedido por teléfono para recoger, ordenar y recoger

1. Entra a la venta:
   - Restaurantes: toca **«Pick-up»** y luego **«Nueva orden»**.
   - Comida rápida: toca **«Pedidos»** y luego **«Nuevo para recoger»**.
2. En **«¿A nombre de quién?»**, escribe el nombre del cliente para reconocerlo cuando llegue, o
   toca **«Omitir»**.
3. Agrega los productos y toca **«Enviar a cocina»**.

**Qué pasa después:** el pedido queda en la lista de **«Pick-up»** (en comida rápida, en
**«Pedidos»** → **«Pick-up»**). Cuando el cliente llega, toca la cuenta y cóbrala con el botón de
cobrar.
**Si algo falla:** si el cliente no llega, cancela la cuenta antes del corte
([Cómo cancelar productos o una cuenta](vender-en-la-caja.md#cómo-cancelar-productos-o-una-cuenta)).
**Relacionado:** [Cómo tomar un pedido a domicilio](#cómo-tomar-un-pedido-a-domicilio)

## Cómo configurar colonias y zonas de envío

**Quién:** dueño o administrador · **Dónde:** Panel → Ajustes → Mi negocio → Zonas de envío · **Plan:** todos · **Giros:** negocios con domicilio
**Lo piden así:** costo de envío, zonas de reparto, colonias, a dónde entregamos, cobrar el envío

Cada zona tiene su costo de envío, y a cada colonia le asignas una zona.

**Zonas:**

1. Entra a **Ajustes → Mi negocio → Zonas de envío**, pestaña **«Zonas»**.
2. Elige la **«Sucursal»** y toca **«Nueva zona»**.
3. Escribe el **«Nombre»** (por ejemplo “Centro”) y el **«Costo de envío (MXN)»**.
4. Toca **«Guardar»**.

**Colonias:**

1. Abre la pestaña **«Colonias»**.
2. Toca **«Cargar colonias»** para traer las colonias oficiales de tu sucursal, o **«Agregar
   colonia»** para una que falte.
3. Busca las colonias, márcalas, elige la zona en **«Asignar zona»** y toca **«Aplicar»**.

**Qué pasa después:** en la caja, al elegir la colonia del cliente, la zona y su costo se ponen
solos.
**Si algo falla:**
- Desde la caja también puedes crear una zona y cambiar la zona de una colonia, pero para cambiar
  el costo de una zona te pide PIN.
- Borrar una colonia no cambia los domicilios de clientes ni los pedidos ya hechos.
**Relacionado:** [Cómo tomar un pedido a domicilio](#cómo-tomar-un-pedido-a-domicilio)

## Cómo asignar el repartidor

**Quién:** cajero · **Dónde:** Caja → «Domicilio» → el pedido → «Asignar repartidor» · **Plan:** todos · **Giros:** negocios con domicilio
**Lo piden así:** asignar repartidor, quién lo lleva, salió el pedido, mandar el pedido, despachar

1. Cuando el pedido esté listo para salir, en la lista de **«Domicilio»**, tócalo.
2. Toca **«Asignar repartidor»**.
3. En **«¿Quién se lo lleva?»**, elige al repartidor. Si falta, toca **«¿Falta alguien? Darlo de
   alta»**.
4. Si se lleva otros pedidos en el mismo viaje, márcalos en **«¿Se lleva algo más?»**.
5. Revisa el **«Tiempo prometido»** (30 minutos, si no lo cambias).
6. Toca **«Asignar»**.

**Qué pasa después:** el pedido queda marcado como en camino y dice «Repartidor: …». Cuando el
repartidor regrese con el dinero, toca el pedido y cóbralo con el botón de cobrar.
**Si algo falla:**
- La caja no te pide el repartidor sola: hay que tocar **«Asignar repartidor»**.
- Si cobras el pedido sin asignar repartidor, sale «Pedido sin repartidor» y ya no puedes
  asignarlo. Anota aparte quién lo llevó.
- «No hay repartidores…» → dalos de alta en el panel
  ([Cómo dar de alta a un repartidor](personal-y-permisos.md#cómo-dar-de-alta-a-un-repartidor)).
**Relacionado:** [Cómo tomar un pedido a domicilio](#cómo-tomar-un-pedido-a-domicilio)

## Cómo editar los datos de una entrega

**Quién:** cajero · **Dónde:** Caja → «Domicilio» → el pedido → «Editar» · **Plan:** todos · **Giros:** negocios con domicilio
**Lo piden así:** cambiar la dirección, corregir el domicilio, otra dirección, me equivoqué de dirección, cambiar cliente del pedido

1. En la lista de **«Domicilio»**, toca el pedido.
2. En el recuadro de la entrega, toca **«Editar»**.
3. Corrige la dirección, o elige otra del mismo cliente, o cambia de cliente.
4. Toca **«Guardar y usar»**.

**Qué pasa después:** el pedido toma la dirección nueva y el costo de envío cambia según su zona.
**Si algo falla:**
- Solo puedes editar pedidos abiertos (sin cobrar).
- Si el pedido viene de la tienda en línea o de una app de delivery, o tiene un canje de lealtad,
  solo puedes corregir la dirección, no cambiar el cliente.
- «Elige una dirección de entrega.» → marca una dirección antes de guardar.
**Relacionado:** [Cómo asignar el repartidor](#cómo-asignar-el-repartidor)
