# Manual de uso de VIM POS

Cómo usar VIM POS, desde que das de alta tu negocio hasta lo más avanzado. Cada tema es un archivo y
cada tarea es una sección que se entiende sola.

- **Para quién:** dueños, encargados, cajeros, meseros y cocina.
- **Qué cubre:** solo lo que hoy funciona en la caja publicada (0.17.0) y en el panel.
- **Precios:** no van aquí porque cambian. Míralos en [vimpos.com.mx/precios](https://vimpos.com.mx/precios).
- **Ayuda:** el WhatsApp de soporte de VIM: +52 56 6508 3346.

Dónde se hace cada cosa:

- **El panel** (admin.vimpos.com.mx): ahí se configura todo. Menú lateral: Inicio, Menú, Inventario,
  Clientes, Agenda, Informes, Personal, Facturación, Ajustes, Tienda en línea y Apps de delivery.
- **La caja** (VIM POS en la computadora o en la tableta): ahí se vende.
- **La pantalla de cocina:** ahí cocina ve los pedidos.
