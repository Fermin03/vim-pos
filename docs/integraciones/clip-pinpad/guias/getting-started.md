# Bienvenidos a Clip

## Descubre el Portal de Desarrolladores

Aquí encontrarás toda la información que necesitas para implementar nuestras APIs y SDKs dentro de tu sistema. ¡Así de fácil!

## Conoce los productos de Clip

Ya sea que implementes un sistema web o una aplicación móvil, las APIs y SDKs te ayudan a crear soluciones de acuerdo a tus necesidades.

### Acepta pagos con tarjeta en tu tienda en línea:

* [API de Checkout Redireccionado](https://developer.clip.mx/docs/api-de-checkout)
* [API de Checkout Transparente](https://developer.clip.mx/docs/api-de-checkout-transparente)
* [SDK de Checkout Transparente](https://developer.clip.mx/docs/sdk-de-checkout-transparente)

### Genera reportes:

* [API de Transacciones](https://developer.clip.mx/docs/api-de-transacciones-1)
* [API de Depósitos](https://developer.clip.mx/docs/api-de-depósitos-1)

### &#x20;Habilita pagos presenciales con tarjeta física a través de la API de PinPad y el SDK Terminal de Clip.

* [Api PinPad](https://developer.clip.mx/docs/api-de-pinpad)
* [SDK Terminal](https://developer.clip.mx/docs/api-de-pinpad)

No olvides consultar la sección de [referencia técnica](https://developer.clip.mx/reference/token-de-autenticacion) para conocer los pasos que debes seguir para integrar nuestras APIs y SDKs.
