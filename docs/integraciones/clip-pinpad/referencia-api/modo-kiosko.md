# Modo Kiosco

En algunos casos de uso es necesario tener las terminales de manera “autónoma” y que realicen cobros donde puede no existir un responsable de la terminal y su comportamiento.

La funcionalidad del modo kiosco permite que las terminales tengan algunas limitaciones y únicamente le permitan al cliente realizar un pago.

¿Qué cambia al habilitar el modo Kiosco en tus terminales?

* En la pantalla principal no se mostrará el icono para ver el perfil que inició sesión.

El resto de preferencias y maneras de generar las solicitudes de pago no se verán afectadas.

## Preguntas frecuentes

**¿Cómo cierro sesión si necesito cambiar de usuario?**

* Para cerrar la sesión de dispositivos en modo kiosco es necesario irse al menú principal del dispositivo > configuraciones > apps > clic en “Clip pinpad” > Borrar almacenamiento
* De esta manera cuando se abra la app de Clip pinpad tendrás que iniciar sesión de nuevo
