# Introducción al SDK Terminal 

El SDK del Terminal de Clip te permite integrar tu aplicación de punto de venta android con nuestros terminales, lo que te permite aceptar pagos en persona a través de nuestra aplicación PinPad. Esta integración garantiza un flujo transaccional fluido y seguro tanto para comerciantes como para clientes.

## Requerimientos mínimos

Para utilizar con éxito la integración del SDK del Terminal, asegúrate de lo siguiente:

* **Coordinación para la integración**: Antes de comenzar, contacta a nuestro equipo a través de <sdk@clip.mx> para validar tu proyecto y coordinar la adquisición de las terminales Clip compatibles que utilizarás durante las pruebas.
* **Android Nativo:** Tu APK debe ser para una aplicación nativa de Android.
* **Verificación de Seguridad:** Deberás compartir tu APK con nuestro equipo de InfoSec para una verificación de seguridad.
* **Instalación del APK:** Una vez que la aplicación sea aprobada por el equipo de InfoSec, se instalará en los dispositivos.
