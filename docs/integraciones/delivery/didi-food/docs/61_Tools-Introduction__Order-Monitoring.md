## Order Monitoring

In the section for [Order Monitoring](https://developer.didi-food.com/en-US/app/order/app) you have 3 tools to monitor the orders of the integrated stores on your application:

### Real-time Monitoring

In the **Real-time Monitoring** panel, you'll be able to see all orders from an app or a selected store by status on a given day in real-time:

![Limitations: B-App Versions Vs. Integration](http://img0.didiglobal.com/static/soda_public/do1_bElp4ESpUdP9kaRwgEKD)

### Store List

In the **Store List** panel, you'll be able to compare the performance of all the stores of an app, by status on a selected period (limited to the last 7 days).

![Limitations: B-App Versions Vs. Integration](http://img0.didiglobal.com/static/soda_public/do1_guTi87yQefgXWEx7Sils)

### Store Order Monitoring

In the **Store Order Monitoring** panel, you'll see a list of all the orders of a certain store and its status in real-time from the last 7 days..

![Limitations: B-App Versions Vs. Integration](http://img0.didiglobal.com/static/soda_public/do1_wAWyDCcaqg2KU21pihdN)
