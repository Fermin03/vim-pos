## Changelog

#### on Mar 17, 2022
Add optional request parameter `show_real_id` to endpoint: **Menu API > Get Store Menu Details**

#### on Mar 2, 2022
Add required field `tax_rate` to endpoints related to item in Japan.

#### on Mar 1, 2022
2 new endpoints released to resolve the problem that couldn't update head image by image url : **Menu API > Upload Image**, **Menu API > Get Image Url List**

#### on Feb 10, 2022
2 new endpoints released to optimize the delivery scheme: **Order API > Order Ready**, **Order API > Order Delivered**

#### on Sep 16, 2021
v3 of 5 new endpoints to manage menus, all under **Menu API**. Old versions moved to the **Old Endpoints Versions** section of the menu.

#### on Aug 23, 2021
4 new endpoints released to configured delivery area for stores handling their one delivery: **Store API > Set Store Delivery Area**.

#### on Jul 23, 2021
New endpoint released: **Store API > Set Store Order Confirmation Method**.

#### on Mar 1, 2021
For now, you can get promotions in webhook with type *OrderNew* and **Order API > Get Order Detail** endpoint. For more details, please check **Order API > Promotion Support**.

#### on Jan 20, 2021
New version release of **Menu API > Upload Store Menu Details** endpoint.
