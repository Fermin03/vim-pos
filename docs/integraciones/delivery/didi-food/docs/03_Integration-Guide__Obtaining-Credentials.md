## Credentials

### Obtaning Credentials


**STEP 1: Please register yourselves as a Developer in [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)**

 1. **How to create an account:**  [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Our Tools > Creating an account

 2. **How to sign in:** [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Our Tools > Sign in

**STEP 2: Create a Business Profile in our [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)**

 3. **Use this section:**   [DiDiFood Developer Website - Qualifications](https://developer.didi-food.com/en-US/app/qualifications/statistical)
    (Tip: If you don’t have the DUNS, please add the Tax ID of your company)

 4. **Create your profile:** [DiDiFood Developer Website - Qualifications](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Qualification Management

 5. **Notify us:** Once submitted please write an email to  globalsupportapi@didiglobal.com so that we can check your profile and see  whether you need to sign a **Technology Integration Agreement** with DiDiFood. If we need to sign the **Technology Integration Agreement**, you will need to provide further information such as:
	* Business Registration Document (Acta Constitutiva/Registro Mercantil)
	* Tax Registration Form (NIT/RFC/NUT)
	* Power of Attorney (Poder Notarial)
	* Legal Representative ID (Identificacion del representante legal)

**STEP 3: Create your credentials:**

 7. **Create an Developer APP (Testing & Production Environment):**  [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Application Management > Creating an app

 8. **Connect current Developer APP to your account:** [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Application Management > Connecting an App *(This applies only when previously DiDi has already granted you access to a Developer APP)*

 9. **Create a testing store:**  [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Application Management > Adding a test store

 10. **Request DiDiFood testing account:** Please submit a [Request Form](https://docs.google.com/forms/d/e/1FAIpQLSeRCK1oVSl1lsD0KTXDpTBmsrviYJcJ5DcEmvc-f-k4jC3axQ/viewform) > Get a testing account for DiDiFood APP (Consumer APP)

 11. **Co-work with your coworkers:** Grant access to the functions of [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi) to another coworker by following these steps -- [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi)  > Tools Introduction > Permission Management

### Understanding Our Credentials

###After creating your credentials following the instructions above, you will have

| **Platform** | **Function** | **What I get with this credential** |
| --- | --- | --- |
| DiDiFood Developer Website Credentials | Is the one that you used to sign up into this website: [DiDiFood Developer Website](https://developer.didi-food.com/en-US/openapi) | Used by Developers to login into this website and obtain the benefits to create/use/adjust the integration functions |
| DiDiStore Testing Credentials | Is the cellphone number you used to create a testing Store in accordance to the section 9 of the STEP 3 above | Use for you to check how orders/menu/promotions flows in our DiDiStore APP or program |
| DiDiFood Testing Credentials | Is the testing account provided by us for you to sign in our DiDiFood APP (Consumer APP) |Used for you to place a test order in our DiDiFood APP (Consumer APP); it begins with “000”, has a fixed verification code and has a validity until 2 months after it is shared. If you want to get another testing code, please submit a request with this link [Request Form](https://docs.google.com/forms/d/e/1FAIpQLSeRCK1oVSl1lsD0KTXDpTBmsrviYJcJ5DcEmvc-f-k4jC3axQ/viewform) > Get a testing account for DiDiFood APP (Consumer APP); these credentails are only provided to identified persons |
