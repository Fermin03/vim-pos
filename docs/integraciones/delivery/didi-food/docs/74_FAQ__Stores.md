## Stores

**Terminology and Meanings**
What is the meaning of each value of `auto_switch`?

There are 3 possible values: 1: Set store online automatically; 2: Set store offline automatically; 3: Set store both online and offline automatically (wich we recommend use in all stores). The complete documentation is on **Store API > Set Store Status**.

**What does type in shop_phone means?**
0: Mobile phone (_default_); 1: Landline


### Binding Stores

**How to connect shop_id with the id in my POS system?**
We provide you with different ways to connect/bind stores between DiDi and the POS system. We explain these ways in **Introduction Guide > Basic Process Overview** in the section **Expansion and Monitoring**.

### Store Operation

**Does PC web version of the app support opening stores?**
No, we recommend downloading the app (Windows or Androind) for opertating stores.
