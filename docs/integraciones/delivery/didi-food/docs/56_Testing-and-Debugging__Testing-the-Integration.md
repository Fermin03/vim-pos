## Testing the Integration

### Order Injections with Sandbox

We have a sandbox enviroment to send orders to your application. Check how to use it in **Tools Introduction > Sandbox Enviroment**.

### Using a Test Store

We provide you a way to create a fake order on the customer's app to a test store so you can see if the order's information is being sent correctly, test how to confirm and cancel the order. To do so, follow the steps below:

1. If you don't have a test store yet, create one following the steps in **Tools Introduction > Application Management**.

2. Have in hands a customer's test credentials. This is a fake customer account that is able to see the test stores on DiDiFood's app (C-App). If you didn't receive this credentials, ask our team.

3. Check the possible store locations below depending on your country. You'll have to use a near by location as the customer.

4. Follow the flow exemplified on the chart below.

5. Check this [step by step guide](https://img0.didiglobal.com/static/starfile/node20211001/895f1e95e30aba5dd56d6f2ccf768b57/B4PjbNvMCO1633046793552.zip) if you need more details.
