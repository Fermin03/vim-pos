## Permissions Management

Administrators of a company account can add other users to benefit from our tools and edit their information too. To do so, go to the **Permissions Management** section.

![Permissions Management](https://pt-starimg.didistatic.com/static/starimg/img/1lWpnWi6Uc1639035116486.gif)

If you didn't added any user yet, the only one you'll see here is your information. Now you can click on **Add Permissions** to add new users and then, you will be able to select the role:

* **Administrators**: Adding a new administrator will give them the same permissions as you have. So, they will be able to create and connect apps and see their information, create test stores, operate stores and use the monitoring and sanbox tools. They will also be able to add and edit new administrators and standart users. We suggest this permission to be given to developers and product people in the integration project. Administrators can view, edit and operate all apps of the company.
* **Standart Users**: If you select the Standart User permission, a new field will open so you select one or more apps of your company. This permission will give them the ability to use **Order Monitoring**, **API Monitoring** and **Store Management** tools for the selected apps. We recommend that you add the operators of the stores as users, so they can perform store binding and management operations.
