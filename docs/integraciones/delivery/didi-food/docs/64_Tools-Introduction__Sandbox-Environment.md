## Sandbox Environment

Our **Sandbox Environment** is a great tool to simulate and confirm orders. With it, we can send  _orderNew_, _orderFinish_ and _orderCancel_ notifications to your callback address. You can even use a real `app_item_id` to check if POS is processing the order information correctly. Check how to use it below:
