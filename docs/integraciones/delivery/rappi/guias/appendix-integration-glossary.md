
# Apéndice - Glosario de Integración

La siguiente tabla contiene los términos más comunes utilizados por Rappi y sus descripciones:

| Término             | Descripción                                                                                                           |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Aliado              | Las empresas y particulares que forman parte del catálogo de Rappi.                                                   |
| POS (Point Of Sale) | El principal punto de venta que Rappi registra para el aliado. Aquí es donde configuras marcas, tiendas y contenidos. |
| Marca               | Los diferentes nombres comerciales que Rappi registra para el POS del aliado. Puede asignar varias marcas a su POS.   |
| Tienda              | Las diferentes opciones de establecimientos de venta que tiene la marca.                                              |
| Menú                | La lista de artículos disponibles por tienda de la marca.                                                             |
| Item                | Los productos disponibles en los menús que pueden pedir los usuarios.                                                 |
| Item ID             | El identificador que Rappi otorga a un artículo al crearlo en el sistema.                                             |
| Item SKU            | El identificador que el aliado otorga a un artículo al crearlo en el sistema.                                         |
| Pedido              | La lista de artículos que los usuarios solicitan a una tienda a través de la aplicación de Rappi.                     |
| Descuento           | Las campañas de reducción de precio disponibles para los artículos del menú.                                          |

Rappi usa estos términos durante el proceso de integración. Si durante cualquiera de los pasos de la integración del API, encuentras un término con el que no estás familiarizado, consulta esta sección para obtener información.
