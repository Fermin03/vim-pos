Aplica para: Factura de retención y Complemento de Servicios para Plataformas Tecnologicas

            Ruby

**La referencia de esta llamada es:**

-  [Obtiene el detalle de la retencion con el Id especificado](https://apisandbox.facturama.mx/docs/api/GET-Retenciones-id)

#### Obtener el detalle de la retencion

#### GET

```
https://apisandbox.facturama.mx/Retenciones/{id}

    Ejemplo:
    https://apisandbox.facturama.mx/Retenciones/hbPAmkJYETg98XHpq4dASw2
```

		**{id}**:  Id de la retención, obtenido al momento de [crearla](https://apisandbox.facturama.mx/guias/retenciones) o en el [listado](guias/retenciones/filtrar)
