# Descargar los sellos CSD digitales de pruebas

	Al usar los CSD debes contemplar que para CFDI 4.0 debes usarlos de acuerdo a los lineamientos de esta nueva versión

	Razón social en mayúsculas sin régimen societario

	[Ver los lineamientos para CFDI 4.0](https://apisandbox.facturama.mx/guias/cfdi40/migrar-cfdi40)

	Los CSD aquí expuestos solo se pueden emplear en el ambiente de pruebas y las facturas generadas con ellos son apoctrifas (no tienen valor ante el SAT).

	Todos las llaves privadas proporcionadas se utilizan con el password **12345678a**
