# Postman con las peticiones más comunes

Te recomendamos descargar y usar durante la integración de nuestra API, el ["Archivo Postman" con las peticiones más comunes.](https://github.com/Facturama/facturama-postman-sdk)

    Para usarlo requieres tener instalado:

    **Postman API Client**

    Es una herramienta que nos permite:

- Enviar solicitudes

- Inspeccionar la respuesta

- Depurar fácilmente

    Puedes descargarlo de [éste enlace.](https://www.postman.com/downloads/)
